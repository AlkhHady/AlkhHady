## About Me

I'm a technology enthusiast focused on understanding how systems work, how they fail, and how they can be made more secure.

My primary interest lies in **offensive security**, particularly Red Team operations, vulnerability research, and low level system exploitation.

Beyond cybersecurity, I enjoy building software and experimenting with technologies across different areas of engineering.

- Interested in Red Teaming and offensive security.
- Exploring reverse engineering and binary exploitation.
- Learning Linux internals, system architecture, and low level programming.
- Building software projects that combine practical engineering and problem solving.
- Continuously documenting my learning process and technical research.
